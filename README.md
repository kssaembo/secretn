# 시크릿 넘버 · 학급 에디션

기존 단일 HTML 시제품을 React + TypeScript + Vite 구조로 재구성한 배포용 프로젝트입니다. 교사 운영 화면이 게임의 기준 상태를 보관하며, 콘택트룸과 결과지 제출 기기는 PeerJS(WebRTC)로 일시 연결됩니다. 게임을 초기화하거나 교사 운영 화면을 닫으면 데이터가 휘발됩니다.

## 실행

```bash
pnpm install
pnpm dev
```

배포 파일 생성은 `pnpm build`, 자동 검증은 `pnpm test`를 사용합니다. 빌드 결과는 `dist` 폴더에 만들어집니다.

## 화면 주소

- `/` 메인 화면
- `/setup` 게임 사전 설정
- `/host` 교사 운영 페이지
- `/board` 교실 전광판(교사 컴퓨터의 별도 창)
- `/station?code=게임코드&room=1` 콘택트룸 태블릿
- `/submit?code=게임코드` 학생 결과지 제출

## 운영 조건

- 교사 운영 페이지가 열린 동안에만 콘택트룸과 결과지 제출이 연결됩니다.
- 전광판은 같은 교사 컴퓨터에서 별도 창으로 여는 구성을 기준으로 합니다.
- WebRTC 연결을 위해 인터넷 연결과 PeerJS 시그널링 서버 접근이 필요합니다.
- 학교망 정책에 따라 P2P가 막힐 수 있으므로 납품 전 실제 학교 Wi-Fi에서 여러 기기로 점검해야 합니다.
